# 旅游宝

> 零决策旅行助手：答得短，带数字，能照做。

「旅游宝」的目标不是做"更聪明的行程规划器"，而是做**途中决策的接管器**：系统被动感知你的体力与情境，在你开口之前给出一个可以立刻执行的动作，你只保留否决权。

> 📌 约定：每次提交更新代码时，同步更新本 README 的进度清单与架构说明（CI 会在只改代码不改 README 时给出警告）。

## 当前进度（v0.8.x）

### 已实现

- ✅ **朗读恢复"全文合成、整段播放"+ 发版前真网测试（v0.8.2）**：
  - 应用户要求撤掉 v0.7.5 引入的分句预取流水线（边合成边播、后台预取下一段），恢复最初方案的模型：**全文合成完整音频 → 整段播放 →（超长才）合成下一段 → 播放**，严格串行、不并发不预取——常见回答（≤800 字）就是一整段音频一次播完，从结构上杜绝乱序与拼接破音
  - 引擎链保留：Edge（免费）→ 硅基流动 CosyVoice2（配 Key 自动启用）→ 系统 TTS；播放完成检测保持轮询式
  - **发版前本地真网测试**：新增 JVM 单元测试（CI 不跑，本地发版前必跑）——Edge 实网合成验证协议有效（本机实测 33.7KB 有效 MP3）、CosyVoice2 兜底请求路径、分段规则（短文整篇一段/长文每段≤800 字/纯标点不触发合成，后者测试抓到全角标点被误判为内容的 bug，已修）
  - 本机测试结论：Edge 协议本身没坏，手机端失败是设备到微软服务器的网络/时钟问题——这正是 CosyVoice2 兜底（同一硅基流动账号、手机端实测可用）要顶上的场景

- ✅ **朗读三级引擎链 + 通话文字稿 + 全卡片可复制（v0.8.1）**：
  - **朗读三级引擎链**：单段合成改为 Edge（免费主力）→ 硅基流动 CosyVoice2-0.5B（配了「语音识别 Key」自动启用，普通 HTTP 比 WebSocket 抗抖动）→ 系统 TTS 兜底，每级自带重试——"播几句就断、报合成不可用"不再让剩余段落陪葬（CosyVoice2 按字节微量计费，一条回答不到 1 厘钱，只有 Edge 失败时才会用到）
  - **修"播一会就不播了"的一个根因**：部分手机 ROM 的 MediaPlayer 播放完成回调不触发，流水线会永久挂死；改为轮询 `isPlaying` 判断播完，播完/出错/被新播报接管都能可靠退出，顺带消掉了强杀播放器时的"破音"
  - **语音通话默认显示会话文字稿**：通话界面中间常驻对话文字（含正在生成的流式回答，实时滚动），看得见 AI 说了什么，也可长按选中复制
  - **所有消息卡片文字可自由选择复制**：提问页与长辈模式的用户气泡、回答卡（正文/要点/建议）、流式输出卡全部支持长按选中、自由复制

### 未实现（按推演方案排序，后续迭代）

- ⬜ 视频通话（AI 真人般实时视频对话）：开源免费方案做不了——真正的全双工视频对话需要实时全模态大模型（如 GPT-4o 级别的语音+视频流式推理），按量计费很贵，与本项目"能免费就免费"的原则冲突。当前的免费替代：**语音通话**（全屏通话界面，按住说话松手即问，回答自动朗读）+ **拍照提问**（对准眼前的事物拍一张直接问），两者组合已覆盖"长辈想边看边问"的主要场景
- ⬜ 公共信息飞轮（脱敏贡献公共池：需要用户明示授权 + 轻量后端）
- ⬜ 群体情境层（"汝之蜜糖彼之砒霜"：按同行结构/体力档位加权证据）+ 推荐多样性（探索意愿状态变量）
- ⬜ 足迹热力图与多日轨迹管理（当前只叠加最近轨迹）
- ⬜ 完全离线的端侧语音模型（当前语音方案云端优先，省电且零体积；端侧需引入 sherpa-onnx 类原生库 + 模型下载管理）
- ⬜ 交通时刻表类硬信息的专项数据源接入

首次启动 → 「设置」→ 选服务商（默认 DeepSeek）→ 填入 API Key → 测试连接 → 保存。可选：填高德 Key 解锁附近搜索与步行路线；去「离线地图」下载所在省份；家里有老人打开「长辈模式」。

DeepSeek API Key 在 [platform.deepseek.com](https://platform.deepseek.com/api_keys) 申请；高德 Key 在 [lbs.amap.com](https://lbs.amap.com) 申请（Web 服务类型）。所有 Key 只保存在本机 DataStore。

## 自动发版与签名

推送到 `main`（或在 Actions 手动 Run workflow）即自动：构建 release APK（正式签名，密钥从 GitHub Secrets 解密，未配置时回退 debug）→ apksigner 验证 → 发布 Release（说明按 commit 生成，自动清理同版本旧构建）。

- 发新版本：修改 `app/build.gradle.kts` 的 `versionName`，tag 自动跟随
- ⚠️ keystore 与密码务必备份（丢失即无法再升级），当前保存位置见仓库外 `lvyoubao-release.jks`

## 架构

```
app/src/main/java/com/lvyoubao/app/
├── data/
│   ├── AiClient.kt            # AI 接口：Function Calling 循环 + 搜索注入 + 视觉 + 纯文本对话
│   ├── AppTools.kt            # 工具执行器：search_poi / get_weather / get_route
│   ├── AmapClient.kt          # 高德：POI 检索 / 步行路线 / 地理编码
│   ├── WeatherClient.kt       # Open-Meteo 实时天气
│   ├── BRouterClient.kt       # BRouter AIDL 联动（离线高程路由）
│   ├── RuleValidator.kt       # 规则校验层（≤2句/含数字），提示人性化且客观
│   ├── SessionStore.kt        # 多会话存储（新建/删除/搜索）
│   ├── MemoryStore.kt         # 个人飞轮：收藏证据 + 相关性检索注入
│   ├── NoteStore.kt           # 随手记存储（JSONL）
│   ├── TrackStore.kt          # 感知轨迹点存储（JSONL，供地图叠加）
│   ├── LocationContext.kt     # 位置上下文（脱敏坐标 + Geocoder 反解城市）
│   ├── UpdateChecker.kt       # 应用内更新（API + atom 双层检查，代理优先）
│   ├── ConfigSync.kt          # 扫码同步配置：载荷编解码（局域网推送 + 配置直带两种二维码）
│   ├── ConfigSyncServer.kt    # 扫码同步接收端：一次性本地 HTTP 服务（ServerSocket + 口令校验）
│   └── observation/           # 疲劳积分观测（引擎 + JSONL 存储 + CSV 导出）
├── sensing/
│   └── FatigueSensingService.kt   # 被动感知前台服务（硬件计步 + LocationManager + 轨迹落点）
├── ui/
│   ├── ask/                   # 对话主界面：消息流 + 合并输入卡（按住说话）+ 快捷开关 + 抽屉
│   ├── common/                # EdgeTts（云端朗读）+ TtsPlayer + SpeechInput（系统识别/大模型转文字，方言口音模型）
│   ├── elder/                 # 长辈模式：会话流 + 底部常驻操作区 + 按住说话 + 拍照提问 + 对话历史 + 语音通话
│   ├── map/                   # 离线地图：mapsforge 查看器 + 中文省区 + 路线/足迹叠加
│   ├── notes/                 # 随手记 + 自动游记
│   ├── observation/           # 感知日志：积分、指标、真实感受标记、回测分析
│   ├── memory/                # 我的记忆（收藏的证据）
│   ├── settings/              # 设置：AI 服务 / 扫码同步 / 外观 / 长辈模式 / 关于
│   ├── sync/                  # 扫码同步：二维码渲染 + 扫码界面（Camera1 + ZXing，兼容 API 21+）
│   ├── update/                # 应用更新页
│   └── theme/                 # Material 3 品牌配色（深海青 + 日出橙）
└── MainActivity.kt
```
